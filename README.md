NationStat — real national statistics for 15 countries, from the World Bank. Rankings you can search, filter and re-sort, a page per country with nine 2024 indicators and ten years of GDP and population charts, and a side-by-side compare view. Static files, no framework, no network requests: it runs offline on a desktop or a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
